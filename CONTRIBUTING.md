# Contributing to Grovely

Thanks for your interest in the project.

## Bug reports

Open a GitHub issue with:
- What you expected to happen
- What actually happened
- Your setup (Docker version, host OS, browser/device if frontend)
- Relevant logs (`docker logs grovely-prod-backend`)

## Pull requests

Bug fix PRs are welcome. Before opening one:
- Check if there's already an issue for it. If not, open one first so we can discuss
- Keep the scope tight, one fix per PR
- Don't change formatting or style outside the fix

Feature PRs are not accepted without prior discussion. Open an issue first and wait for a response before writing any code. Feature direction is maintained by the project.

## Licensing

By submitting a pull request you agree that your contribution may be used in any part of Grovely, including premium features.
